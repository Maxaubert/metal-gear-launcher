does not use the extracted MGS1 launcher logo. Playnite's collection branding supplied the
reference direction for upright, condensed lettering. Playnite files were not modified.

Generation brief: create an original neutral wordmark containing exactly METAL GEAR SOLID on
one line, bold condensed upright uppercase lettering, balanced spacing and crisp edges. No game
number, subtitle, creator credit, tagline, underline, icons, texture, glow or bevel.

Final edit prompt: retain the generated letterforms and layout, replace the background with
uniform pure black, and make the lettering flat white with sharp antialiased edges. The UI
