# Extraction spike, 2026-09-06

What was verified on this machine while building the packs (`shared/packs/*.json`) and the
extractor (`electron/main/extract/`) for Task 2 onward. This is the source for those pack
values; if a game updates and an asset name or path moves, re-verify here before touching the
pack JSON.

## Tools

| Tool | Repo | Used for |
|---|---|---|
| AssetStudioModCLI (net9, win64) | `aelurum/AssetStudio` | Unity `.bundle` and `.assets` extraction (MG1&2, MGS2, MGS3, MGS4, Peace Walker) |
| FreeMote (`PsbDecompile.exe`) | `UlyssesWu/FreeMote` | M2 engine `.psb`/`.psb.m` decompilation (MGS1 only) |

## Unity launchers (MG1&2, MGS2, MGS3, MGS4, Peace Walker)

Every one of these five games ships a separate Unity launcher app alongside the real game exe.
The launcher's `StreamingAssets/aa/StandaloneWindows64/` addressables tree holds one
`animator.prefab.bundle` per game with the five hero-art sprites (`Texture2D`) as separate
objects inside it, one `bgm/<game>/*.wav.bundle` with the menu loop (`AudioClip`), and the
shared launcher fonts `MG-RodinProN-M`/`MG-RodinProN-B` (`Font`, exported as `.otf` by
AssetStudioModCLI, not `.ttf` as originally assumed) in `sharedassets0.assets` at the launcher
root.

Bundle path and object-name conventions per game (exact values live in the pack JSON, this is
the pattern they follow):

| Game | Launcher root | Bundle folder | Font/shared-assets path |
|---|---|---|---|
| MG1&2 | `launcher_Data/` | `packedassetsmg12_assets_launcher/` | `launcher_Data/sharedassets0.assets` |
| MGS2 | `launcher_Data/` | `packedassetsmgs2_assets_launcher/` | `launcher_Data/sharedassets0.assets` |
| MGS3 | `launcher_Data/` | `packedassetsmgs3_assets_launcher/` | `launcher_Data/sharedassets0.assets` |
| MGS4 | `Launcher/launcher_Data/` | `packedassetsmgs4_assets_launcher/` | `Launcher/launcher_Data/sharedassets0.assets` |
| Peace Walker | `launcher/launcher_Data/` (lowercase `launcher`) | `packedassetsmgspw_assets_launcher/` | `launcher/launcher_Data/sharedassets0.assets` |

Object names are not systematic across games (e.g. MGS4/Peace Walker use
`ui_launcher_bg_main_<game>` / `ui_launcher_logo_<game>`, MGS2/MGS3 use `<GAME>_MainVisual` /
`<game>_logo`, MG1&2 mixes both conventions and reuses `mg12_grid_mask` for two roles). Each
name was found by extracting every `Texture2D`/`Font`/`AudioClip` in the relevant bundle with
no name filter, then narrowing by eye; the filtered command used in the packs is:

```
AssetStudioModCLI.exe <bundle-or-.assets> -o <outDir> -t Texture2D -g none --image-format png --filter-by-name <exact-name>
AssetStudioModCLI.exe <bundle> -o <outDir> -t AudioClip --audio-format wav --filter-by-name <exact-name>
AssetStudioModCLI.exe sharedassets0.assets -o <outDir> -t Font --filter-by-name MG-RodinProN-M
```

MGS4's BGM bundle lives under a different addressables group than the rest
(`packedassetsmgs4_assets_scenarioapp/mgs4/bgm/`, not `_assets_launcher/`) - verified by
searching the whole `StreamingAssets/aa` tree for `.wav.bundle`, not assumed from the other
four games' pattern.

## M2 engine (MGS1)

MGS1 alone still runs on the older M2 engine and ships no separate launcher; its menu art and
music live inside `system/motion/outgame_menu_main.psb.m` (an MDF-shelled, PSB-encoded sprite
atlas) and `system/sound/bgm_title.psb` (unshelled) under the install root, referenced through
`windata/alldata.bin` + `windata/alldata.psb.m` (an offset/size table keyed by in-archive path).

- **MDF seed:** `25G/xpvTbsb+6`, key length **64**. Verified against the real install: the key
  alone does not decrypt any `.psb.m` file in this archive - FreeMote's MDF seed is
  **key + filename** concatenated into one string (`electron/main/extract/tools.ts`'s
  `psbFileArgs`), confirmed by successfully decompiling `alldata.psb.m` and
  `outgame_menu_main.psb.m` with `seed = "25G/xpvTbsb+6" + basename(file)`.
- **Manifest command** (decodes `alldata.psb.m` into the offset/size table):
  `PsbDecompile.exe -s 25G/xpvTbsb+6alldata.psb.m -l 64 -o <outDir> alldata.psb.m`
- **Per-file command** (once the file's bytes are sliced out of `alldata.bin` by offset/size
  from the manifest, e.g. into `outgame_menu_main.psb.m`):
  `PsbDecompile.exe -s 25G/xpvTbsb+6outgame_menu_main.psb.m -l 64 -o <outDir> outgame_menu_main.psb.m`
- **Atlas sprite ids** inside the decoded `outgame_menu_main.psb.m.json`, texture `tex#000`
  (the pack schema's default): `0019` main visual, `0012` logo, `0007` numbering, `0015` year,
  `0045` bg effect. Each is a `{ left, top, width, height }` rect in the atlas JSON's
  `source["tex#000"].icon[id]`, cropped out of the sibling `tex#000-texture.png` PsbDecompile
  also produces.
- `bgm_title.psb` decompiles with the same per-file command and produces a `.wav` directly
  (no sprite atlas involved), landing under a `bgm_title` resource folder rather than the
  `-resources` suffix `.psb.m` files get - `findResourceDir` in `electron/main/extract/m2.ts`
  checks both shapes rather than assuming one.

## Launcher settings and fix-mod locations (for the phase-2 settings screen, not built yet)

Recorded here now so the pack schema's future `settings` field does not need a second research
pass; not read or written by anything in this MVP.

| Game | Konami launcher settings file | Fix-mod config |
|---|---|---|
| MGS2, MGS3, MG1&2 | `<game>_savedata_win\<SteamID>\launcher\launcher_sv` (JSON `keyList`/`valueList`: `language`, `HiresoPreset`, `HiresoRender`, `HiresoUpScale`, `HiresoMovie`) | `plugins\MGSHDFix.ini`, `plugins\<game>-Community-Bugfix-Compilation.ini` |
| MGS1 | inside the M2 archive, not user-editable | `MGSM2Fix.ini` next to the exe |
| MGS4 | `mgs4_savedata_win\<SteamID>\launcher\launcher_sv` JSON (`resolution`, `WindowMode`, `language`); `MGS4\config\mgs4.user.ini` for `[render]` overrides (never create `mgs4.ini` directly, it shadows the real config and the game will not start) | `MGS4\scripts\SunnySideUp.ini`, `MGSPatriotFix.settings` (only written once the Config Tool is run and saved) |
| Peace Walker | same shape as MGS4 | `MGSPatriotFix.settings` |

Source: `C:\Program Files (x86)\Steam\steamapps\common\claude\games\metal-gear-master-collection\current-install.md`,
this machine's own modded install, cross-checked against the design spec's section 4.5.
